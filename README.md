# sudoku

My own little adfree sudoku app.

## Tech Stack

- Vite
- Svelte
- TypeScript
- CSS Grid
- vite-plugin-pwa

## Quickstart

1. Install Node.js (LTS).
2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```

5. Preview production build:

```bash
npm run preview
```
